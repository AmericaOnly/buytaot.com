Lesson 01

What is TAOT?

TAOT, The America Only Token, is an ERC-20 token deployed on Base. It has a maximum supply of 250 million tokens and a publicly verified smart contract.

Lesson 02

What is a token?

A token is a digital asset represented by a smart contract on a blockchain. The contract records balances and defines how tokens can be transferred. TAOT follows the widely supported ERC-20 standard.

Each token contract has a unique address. Always verify that address before buying, importing, or transferring a token.

Lesson 03

What is the EVM?

The Ethereum Virtual Machine, or EVM, is the environment that executes Ethereum-compatible smart contracts. Networks such as Base use EVM standards, allowing many Ethereum wallets, applications, and developer tools to work across compatible networks.

TAOT is on Base, so a wallet must be connected to Base when sending or interacting with TAOT.

Lesson 04

Wallets and self-custody

A wallet manages the keys used to authorize blockchain transactions. A public wallet address can safely be shared to receive tokens. A private key or recovery phrase must remain secret because it provides control over the wallet.

Core rule: TAOT representatives will never need your private key or recovery phrase.

Lesson 05

Transactions and gas

A blockchain transaction is a signed instruction, such as sending a token or approving a swap. Base charges a small network fee, commonly called gas, which is paid in ETH. Gas pays the network to process the transaction; it is separate from the token being transferred.

Transactions are generally irreversible. Review the network, destination address, token, amount, and wallet prompt before approving.

Lesson 06

Swaps, pools, and liquidity

Decentralized exchanges use liquidity pools to let users swap between assets. TAOT's primary market is the TAOT/USDC Aerodrome pool on Base. Prices can move as trades change the balance of assets in a pool.

Slippage, price impact, liquidity depth, and network fees can affect a swap. Review the complete wallet prompt before confirming.
