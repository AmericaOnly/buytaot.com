Lesson 01

What is TAOT?

TAOT, The America Only Token, is an ERC-20 token deployed on Base. It has a maximum supply of 250 million tokens and a publicly verified smart contract.

Because TAOT lives on a public blockchain, anyone can independently inspect its contract, token supply, holders, and transfers. The official contract address is 0x7f2f00e54dcaa8b248bdfd75da2ae859d4d8ff3e.

Lesson 02

What is a token?

A token is a digital asset represented by a smart contract on a blockchain. The contract records balances and defines how tokens can be transferred. TAOT follows the widely supported ERC-20 standard.

Each token contract has a unique address. Always verify that address before buying, importing, or transferring a token.

Two tokens can share the same name or symbol, so the contract address is the most reliable identifier. ERC-20 compatibility gives wallets and decentralized applications a common way to read balances and request transfers.

Lesson 03

What is the EVM?

The Ethereum Virtual Machine, or EVM, is the environment that executes Ethereum-compatible smart contracts. Networks such as Base use EVM standards, allowing many Ethereum wallets, applications, and developer tools to work across compatible networks.

TAOT is on Base, so a wallet must be connected to Base when sending or interacting with TAOT.

An EVM address can often be used on several compatible networks, but balances and transactions remain separate on each network. Always check the selected network before taking action.

Lesson 04

Wallets and self-custody

A wallet manages the keys used to authorize blockchain transactions. A public wallet address can safely be shared to receive tokens. A private key or recovery phrase must remain secret because it provides control over the wallet.

Self-custody means the wallet owner controls those keys and is responsible for protecting them. If you lose the 18-word recovery phrase for your TAOT app wallet, the TAOT team cannot retrieve the wallet or its tokens. Store recovery information offline, check addresses carefully, and never enter a recovery phrase into a website reached through an unexpected message.

Core rule: TAOT representatives will never need your private key or recovery phrase.

Lesson 05

Transactions and gas

A blockchain transaction is a signed instruction, such as sending a token or approving a swap. Base charges a small network fee, commonly called gas, which is paid in ETH. Gas pays the network to process the transaction; it is separate from the token being transferred.

Transactions are generally irreversible. Review the network, destination address, token, amount, and wallet prompt before approving.

Always send a small test transaction before transferring a large amount of any token. Confirm that the test arrives at the intended wallet on the correct network before sending the remaining amount.

After submission, a transaction receives a unique transaction hash. That hash can be searched on a block explorer to confirm whether the transaction is pending, successful, or failed.

Lesson 06

Swaps, pools, and liquidity

Decentralized exchanges use liquidity pools to let users swap between assets. TAOT's primary market is the TAOT/USDC Aerodrome pool on Base. Prices can move as trades change the balance of assets in a pool.

Slippage, price impact, liquidity depth, and network fees can affect a swap. Review the complete wallet prompt before confirming.

Liquidity is the supply of both assets available in a pool. Deeper liquidity usually allows a trade to have less price impact, while slippage settings define how much price movement a user will accept before a swap fails.

Lesson 07

Block explorers and on-chain verification

A block explorer is a public search tool for blockchain data. Basescan lets you inspect Base transactions, wallet balances, token holders, contract code, and transaction status without connecting a wallet.

Search with a transaction hash, wallet address, or contract address. Explorer records are useful for verification, but a familiar token name alone does not prove authenticity; compare the full contract address with an official source.

Lesson 08

How smart contracts work

A smart contract is a program stored on a blockchain. It executes defined rules when a user or another contract calls one of its functions. ERC-20 contracts provide standard functions for balances, transfers, supply, and allowances.

Published contract code and activity can be reviewed on a block explorer. A contract interaction may move assets or change permissions, so read the wallet prompt and confirm the contract address before signing.

Lesson 09

Token approvals and allowances

A token approval gives a specific smart contract permission to spend up to an allowed amount of a token from your wallet. Decentralized exchanges commonly request an approval before they can complete a swap.

An approval does not reveal your private key, but an unnecessary or unlimited allowance can create risk if the approved contract is unsafe. Review the contract and amount before approving. You can inspect and revoke existing approvals with a reputable allowance-management tool.

Lesson 10

Bridges and cross-chain transfers

A blockchain bridge moves value or messages between networks. Depending on its design, a bridge may lock or burn an asset on the source network and release or mint a corresponding asset on the destination network.

Bridging is different from a normal same-network transfer. Before using a bridge, verify the official bridge, source network, destination network, token, and destination contract address. Allow time for both networks to confirm the operation.
